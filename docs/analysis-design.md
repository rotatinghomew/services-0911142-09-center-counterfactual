# 反事实分析设计

本文档说明“用其他片区构造反事实”的口径、模型、诊断与边界。页面与服务端共用同一套
实现（`center_counterfactual/analysis.py`），前端不另算统计答案。

## 1. 人群与次数口径

- 处理区固定为 A0，人群固定为**居民归属片区 `resident_area = A0` 的登记居民**。
  中心、上门、总量三个渠道解释的是同一人群，渠道之间可以直接相加与比较。
- 接触按 `source_key` 去重：同一 `source_key` 的重报只计一次，去重条数随结果返回。
- 跨区服务按**居民归属**计入本片区，而不是服务地点；A2 居民在 A0 接受的服务仍计入 A2。
- 输出是**接触次数**（可选按每千登记人口缩放为率）。同一 `household` 可在多周、多渠道
  重复出现，因此任何“次数变化”都不能表述为“受益人数变化”。受益人数需要家庭去重，
  本分析不提供该口径的因果估计。
- 渠道恒等：先在次数尺度分别拟合 `center` 与 `home`，`total` 由两者相加得到，
  保证 `total = center + home` 对实际值与反事实值同时成立。

## 2. 动态对照资格

候选片区不是静态白名单，资格由 `events` 与 `sharing` 按周推出：

- 片区自身在 `events` 中有中心开放记录（如 A3 第70周）：开放周及之后视为受处理，
  不能再充当未受影响对照。
- `sharing` 中与 A0 之间存在 `team`（共享队伍）或 `cross_visit`（跨区服务）的区间
  `[start, stop)`：区间内该片区的服务供给或居民流向受到 A0 影响，区间内记录受污染。
- 进入合成对照的片区必须同时满足：训练窗口内每周都干净、处理后资料覆盖区间内不出现
  污染周、未被分析者手动剔除、`unshared` 范围下未带 `shared_team` 标记。
- 每个片区的排除原因、首个污染周、训练期干净周数都随结果返回并在页面展示；
  受污染片区在页面上为禁用勾选，不能被误当作合格对照。

当前演示资料下，A1（共享队伍，第52周起）、A2（跨区服务，第52周起）、A3（自身第70周
开放中心）均退出处理后对照，合格对照为 A4–A8。

## 3. 模型

- 方法：合成控制法（Synthetic Control Method）。对每个渠道，用合格对照片区的周度
  序列加权重建 A0 的训练期轨迹，权重非负且和为 1（SLSQP 约束最小二乘，多起点求解）。
- 权重**只在训练窗口拟合一次**，处理后不重新拟合、不调参；处理后预测完全外推。
- 训练截止周、留时段（holdout）窗口、安慰剂开放周、候选范围、手动剔除名单均可在页面
  调整并由服务端校验。训练窗口至少12周，留时段必须位于训练窗口内且至少4周。
- 不提供插值或平滑：缺口序列是实际与反事实的逐周差，缺测不补零。

## 4. 诊断与识别门槛

单次个案研究没有常规大样本推断，结论依赖以下诊断，任一不过即 `identified=false`，
页面明确显示“无法识别”，不绘制平滑效果线：

1. **对照拟合质量**：训练期 RMSPE；处理后 RMSPE 不足训练期 2 倍时，效果与拟合噪声不可分。
2. **留时段预测**：训练窗口内划出未参与选权重的 holdout，其 RMSPE 若明显放大说明
   外推能力不足。
3. **安慰剂一（in-time）**：仅用安慰剂开放周之前的数据重新拟合，检查其后到真实开放周
   前的“伪处理期”是否出现同量级缺口或误差放大。
4. **安慰剂二（跨片区）**：每个合格对照片区轮流充当伪处理区，用其余对照重建，
   比较处理区缺口在该分布中的极端程度（排位）。
5. **留一地区（leave-one-out）**：逐个剔除对照片区重拟合，若效果方向改变说明结论
   依赖单一地区。
6. **三渠道恒等**：`center + home = total` 的最大绝对误差必须接近零。

## 5. 演示资料下的预期现象

- 上门（home）：处理后周均缺口约为负、中心（center）约为正，且均通过上述诊断，
  支持“居民由上门转向中心”的渠道替代解释。
- 总量（total）：两渠道缺口近似抵消，处理后缺口与训练期误差同量级，安慰剂排位不极端，
  系统判定**无法识别总量效果**，而不是给出一条看似平滑的总量效果线。
- 这回答了负责人的问题：有证据表明渠道结构改变，没有证据表明服务总量整体减少；
  结论仅适用于 A0 这一个案。

## 6. 留存与外推边界

- 每次研究通过 `POST /api/studies`（带 `title`）冻结到独立 `studies` 表，保存内容包含
  数据版本指纹、完整参数、逐片区资格与原因、权重、全部诊断、逐周实际/反事实/缺口。
- 打开旧研究读取的是冻结结果，后续导入新数据不会重算历史记录。
- 本方法估计的是 A0 在该资料期、该对照池下的个案反事实。合格对照只有数个片区、
  安慰剂分布样本很小，不能把这一处经验推广为全市因果结论；讨论其他解释时，
  应回到冻结的资格名单与权重，而不是只看效果图。
