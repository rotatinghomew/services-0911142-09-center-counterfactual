# 现场复核

先在画外完成依赖或镜像准备。服务就绪检查为 `/health`，启动不下载资料。打开首页，选择服务指标，查看中心开放前后的地区服务时间序列；从任一明细点开原始记录核对。保存一次当前材料，然后改动选择并重新计算，再打开刚才的记录，确认原范围仍在，最后导出。

上述操作的设计时长为45至75秒，留出异常提示时间后不超过90秒。部署故障不隐藏也不回放旧结果。新增分析的实际结果和可操作性须在功能完成后重新验证；这里不预报尚未开发能力的演示结果，不限定显著性或结论方向。

## 反事实研究流程

1. 在“反事实分析”区选择渠道（center/home/total）、候选范围，确认开放周与训练截止周；
   受 `events`、`sharing` 规则判定污染的片区显示为禁用的已排除状态，并注明原因与失效周。
2. 点击“运行反事实分析”，查看实际与合成反事实轨迹、权重、训练期与留时段 RMSPE、
   in-time 与跨片区安慰剂、留一地区结果和识别结论。识别不通过时页面只给“无法识别”，
   不输出平滑效果线。
3. 可手动剔除合格片区、缩短训练窗口或调整安慰剂周后重跑，观察结论对单一地区和
   训练期选择的依赖；切换到 total 渠道可核对总量口径是否可识别。
4. 命名后“冻结保存资格与权重”，在“已冻结研究”中重新打开，确认资格、权重与诊断
   不随后续数据导入变化；需要讨论其他解释时导出研究状态（JSON）。
5. 全程使用接触次数口径，不把次数变化表述为受益人数变化，也不把 A0 个案外推为全市结论。
